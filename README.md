# 🎂 Полет на ДР Жени! 🚀

Браузерная мобильная мини-игра в стиле Flappy Bird, созданная в качестве персонализированного подарка на день рождения.

## 🕹️ Управление и геймплей
- **Тап по экрану / клик мыши / пробел:** импульс прыжка вверх.
- **Бонусы (тортики):** +10 очков.
- **Препятствия (бутылки виски, горящие дедлайны, злые будильники 07:00):** +2 очка за успешный облет.
- **NPC:** пролетающий бро с красными дредами на реактивном ранце с криками поддержки.
- **Пасхалка:** кошечка Сметанка в правом нижнем углу.
- **Жизни:** 3 сердечка с 1.5 сек неуязвимости (мигание) при столкновении.
- **Цель:** 100 очков.
- **Финал:** При наборе 100 очков игра останавливается, запускается салют из конфетти (`canvas-confetti`) и модальное окно с душевным братским поздравлением и кнопкой залпа салюта.

## 🖼️ Кастомные спрайты и оформление
Все спрайты лежат в папке `public/images/`. Если файлов еще нет, игра автоматически использует встроенные SVG-заглушки:
1. `public/images/hero.png` — персонаж Женя (рекомендуемый размер 128x128 или 256x256 px).
2. `public/images/obstacle.png` — дедлайн / грозовая туча (120x120 px).
3. `public/images/bonus.png` — праздничный торт со свечами (96x96 или 128x128 px).
4. `public/images/bg-far.png` и `bg-near.png` (опционально) — зацикленные параллакс фоны.

## 🚀 Сборка и деплой на Vercel
Проект построен на React + Vite + Tailwind CSS и готов к моментальному развертыванию на Vercel (Root Directory: `./`, Build Command: `npm run build`, Output Directory: `dist`).

```bash
npm install
npm run dev
```
